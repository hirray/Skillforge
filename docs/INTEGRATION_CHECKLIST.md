# Integration Checklist

To swap a mock implementation for a real one:
1. Update \`.env\` and set \`{MODULE}_SOURCE=real\`.
2. Run contract tests (\`npm test\`).
3. Run manual smoke test via Web UI.
4. Tell the group.

## Suggested Order
1. Auth
2. Users/Skills
3. Projects/Team
4. Tasks/Chat
5. AI
6. GitHub/Verification
7. Recruiter Modules
