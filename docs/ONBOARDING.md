# Onboarding

1. Clone repo.
2. \`npm run setup\` (Ensure you have Node 20 and Python 3.11).
3. \`npm run dev\`.

## Test Users
Seed users are created with dev login. You can log in via \`dev-login\` bypassing password checks in local dev.
- \`student@example.com\` (user-001)
- \`freelancer@example.com\` (user-002)
- \`admin@example.com\` (admin-001)

## DB Reset
\`npm run db:reset\` resets SQLite db.
