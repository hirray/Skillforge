# SkillForge Standardized Vocabulary & Glossary

**Status**: Frozen for Curation  
**Scope**: All UI copy, navigation labels, headings, buttons, notifications, toasts, and manuals.

---

| Concept | Standard Term | Banned Synonyms (Do Not Use) | Definition & Usage Context |
| :--- | :--- | :--- | :--- |
| **Project** | **Project** | Repo, Repository, Assignment, Gig, Workspace | A collaborative engineering initiative created and delivered on SkillForge. |
| **Team** | **Team** | Squad, Group, Crew, Pod | The group of verified individuals collaborating on a project. |
| **Member** | **Member** | Contributor, Collaborator, User, Worker | An active participant who holds a defined role in a project team. |
| **Role** | **Role** | Title, Slot, Position, Job (in project) | The specific technical capacity of a member (e.g. Frontend Lead, Raft Architect). |
| **Job** | **Job** | Opening, Vacancy, Gig, Listing, Position | An employment opportunity posted by a verified company. |
| **Candidate** | **Candidate** | Lead, Applicant, Prospect, Talent (individual) | An engineer eligible for or active in an enterprise hiring pipeline. |
| **Pipeline** | **Pipeline** | Funnel, Kanban Board, Hiring Board | The stage-by-stage progression of candidates for a specific job (New $\rightarrow$ Contacted $\rightarrow$ Screen $\rightarrow$ Interview $\rightarrow$ Offer $\rightarrow$ Hired). |
| **Challenge** | **Challenge** | Bounty, Contest, Competition, Problem | A real-world technical problem sponsored by a company for teams to solve. |
| **Hackathon** | **Hackathon** | Jam, Coding Contest, Sprint Race | A timed collaborative development event with defined milestone checkpoints. |
| **Mentor** | **Mentor** | Coach, Technical Advisor, Consultant, Guide | A senior expert offering milestone reviews and architectural feedback. |
| **Certificate** | **Certificate** | Badge, Diploma, Proof Token, Credential | A cryptographically attested PDF credential with QR code verifying project completion. |
| **Verified Experience** | **Verified Experience** | Past Work, Proof of Work, Work History | The tamper-evident portfolio record generated from verified project milestones. |
| **Portfolio** | **Portfolio** | Profile Dossier, Showcase, CV, Public Page | The engineer's public-facing showcase of attested skills, certificates, and projects. |
| **Skill** | **Skill** | Keyword, Tag, Technology, Tool | A normalized taxonomy capability attested through repository commits or resume extraction. |
| **Evidence** | **Evidence** | Artifact, Attachment, File Proof, Proof | Commit signatures, PR links, deployment URLs, or documents verifying technical output. |

---

## Sentence Case and Action Rules
1. **Sentence Case**: Always use sentence case for headings, buttons, and labels (e.g. "Create project", "Find talent", "Active projects").
2. **Verb-First Buttons**: Primary buttons must start with an active imperative verb (e.g. "Save changes", "Send invitation", "Post job", "Review submission").
3. **Transparent AI Language**: Always explain *why* an AI recommendation is made (e.g. "94% match because of attested Kafka experience"). Never show a raw bare score without evidence.
